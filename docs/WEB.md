# The web build: hub, loading screens and the playable 2D and 1D modes

`web/` is a static site with no build step and no libraries. It runs from any static server and is
published whole as one claude.ai artifact. The 3D scenes are not here; they are built in Blender
(`docs/BLENDER.md`).

```
web/index.html          the hub (a contact sheet of the ten covers) and the stage the games play in
web/lib/app.js          routes, loading screens, menus, the play frame, the api each mode gets
web/games/<slug>/       loading.js and one <key>.js per 2D mode and 1D game (keys: docs/graphic_styles.json)
web/data/, web/assets/  generated by tools/web/build.py (catalog, stills, pictographs); not versioned
```

Routes are hashes: `#<slug>` opens a game (its loading screen, then its menu), and
`#<slug>--<key>` opens one mode through the loading screen.

## loading.js

```js
export const meta = {
  cover: "assets/stills/<slug>/<stem>.jpg",   // the hub thumbnail and the loading still
  palette: { bg: "#...", fg: "#...", accent: "#..." },   // from DESIGN.md section 15
  fonts: "family=Cormorant+Garamond:wght@500&family=...",  // optional Google Fonts css2 query
  display: "'Cormorant Garamond', Georgia, serif",          // optional font stacks for the menu
  body: "...",
  menuIntro: "One or two sentences that set the game up for its menu.",
};
export function render(root, ctx) {   // ctx: { title, label, still, stills, reducedMotion }
  // draw the loading screen into root (it fills the stage); return a handle
  return { progress(p /* 0..1 */) {}, close() {} };
}
```

A loading screen is the game's own: its palette, type, still, and one animated element that belongs
to its world (a seam being stitched, a lens iris, a torch circle), plus the title, one line from the
source quoted verbatim, and a rotating gameplay tip. It shows for at least 2.2 seconds.

## <key>.js: one 2D mode or 1D game

```js
export default {
  mount(root, api) {   // root fills the stage below the bar (position: absolute; inset: 0)
    // build the game; return { unmount() } that stops every timer, frame and listener
  },
};
```

`api`: `game`, `key`, `title`, `style`, `layer`, `palette`, `reducedMotion`, `rng(seed?)` (a seeded
generator), `store.get/set` (per-mode browser storage, may be unavailable), and `end({ outcome:
"win" | "lose" | "done", text })`, which shows the result with Play again and Back.

Each mode is a playable prototype of the design's rules (DESIGN.md sections 10 and 11) at a small
scope: one level, board or puzzle, two to six minutes. It is drawn in the graphic style the mode
owns (`docs/graphic_styles.json`; its pictograph is the visual reference), works with mouse, touch
and keyboard, opens with a short how-to-play, ends with a win or a loss, and respects reduced motion.
No network requests and no libraries; Google Fonts only through `meta.fonts`. Styles are scoped by a
class prefix so modes cannot collide.

## Commands

```bash
python tools/web/build.py                        # catalog, stills and pictographs into web/
node tools/web/smoke.mjs [slug ...] [--shots DIR] # every route in a headless browser
python -m http.server 8799 --directory web       # play it locally (open /#<slug>)
```
