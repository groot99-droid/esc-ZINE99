Ten games
from one vault

Ten stories from the author's creative-writing vault, each made into a game that moves between 3D places, 2D spaces you cross and 1D puzzles you work out. Pick a cover to load the game and play its 2D modes and 1D games here in the page.

The 3D scenes are built in Blender from each game's build files and are not playable on this page. Every 2D mode and 1D game is drawn in its own graphic style, and no style is used twice across the ten games. Progress is kept in this browser only.
